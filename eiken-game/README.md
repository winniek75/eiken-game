# 🎮 英検クエスト - Eiken Quest

英検5級・4級・3級のレベル別に問題を解きながら、ゲーム感覚で楽しく英語を学習できるWebアプリケーションです。

![英検クエスト](https://via.placeholder.com/800x400/1a1a2e/ff6b9d?text=Eiken+Quest)

## ✨ 特徴

- 🎯 **レベル別学習** - 英検5級、4級、3級の3段階
- 🔥 **中毒性のあるゲームプレイ** - コンボシステム、タイムアタック、ハイスコア
- 🎨 **モダンなビジュアル** - ネオンアーケード風のデザイン
- 🔄 **ランダム出題** - 何度でも楽しめる問題シャッフル
- 📱 **レスポンシブ対応** - PC・スマホどちらでもプレイ可能

## 🚀 デプロイ方法

### Vercel でのデプロイ

1. このリポジトリをフォークまたはクローン
2. [Vercel](https://vercel.com) にログイン
3. 「New Project」をクリック
4. GitHubリポジトリをインポート
5. 自動的にビルド・デプロイされます

### ローカル開発

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev

# ビルド
npm run build
```

## 🎮 ゲームシステム

### スコアリング
- 正解: 100ポイント
- タイムボーナス: 残り時間 × 10ポイント
- コンボボーナス: コンボ数 × 50ポイント

### ランク
- **S**: 正解率90%以上
- **A**: 正解率70%以上
- **B**: 正解率50%以上
- **C**: 正解率30%以上
- **D**: 正解率30%未満
